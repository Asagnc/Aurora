# Owned SDK qualification metadata

These `package.xml` files are copied unchanged from the existing official SDK
installation at platforms/android-37.0 (revision 2) and build-tools/36.0.0.
They are sdkmanager-generated package registration data, including the original
SDK license text; the official ZIPs separately pinned by platform.json and
build-tools.json do not contain these files.

The experiment copies them into its private SDK only. They neither replace SDK
payload validation nor indicate Android, JNI, installation or license closure
qualification. No Android Studio or phone installation generated this copy.
