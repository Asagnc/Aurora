# Skills 实现与验收边界

2026-10-21，0.1.17。用户已批准 SKILLS_PROPOSAL.md，要求保持最新稳定版。

## 已实现

- 标准 SKILL.md/YAML 1.2，真实多行/引用文本解析，元数据与 Markdown 正文分离；未知原文字段保留在内容包中。禁止 YAML 别名、自定义对象标签、重复键与超预算输入。
- 共享 SHA256 内容版本、SQLite WAL 索引/发布恢复日志/会话引用。先暂存校验，再原子移动内容目录，最后提交索引；跨数据库/文件系统不是单个原子事务，启动按恢复日志收尾。
- ZIP 从系统文件选择器、会话文件或公共 HTTPS 导入；GitHub 仓库优先最新正式 release，没有 release 时使用明确标注的默认分支提交快照。解析提交后下载固定 SHA。更新入口重新查询来源，不使用旧提交冒充最新。
- ZIP 限 64 MiB、展开 256 MiB、单文件 32 MiB、4096 条目、中央目录 2 MiB；只接受 Stored/Deflate，不接受 ZIP64、分卷、加密、符号链接/特殊文件、重复路径和文件目录冲突。实际流字节和 CRC 二次验证。
- Agent 五个固定工具：skills_list/load/read/install/manage。目录摘要只显示前 12 项，完整目录支持搜索和游标；skills_read不填path可搜索/分页遍历资源（每页64），指定path按字节游标读取（单次64KiB）。目录变化追加原生历史，不重写旧前缀，不保证供应商缓存命中。
- 每个新任务采用当前安装且启用的版本；运行中默认版本固定，新安装或显式版本读取有独立引用。会话引用保留旧版，删除会话只释放引用；共享包不会随会话删除。清理仅删除未引用且非当前的版本。
- 原生管理页：搜索、安装、ZIP 导入、启停、正文预览、版本选择、检查更新、移除和旧资源清理。通过已有事件 StateFlow 更新，无定时轮询/常驻进程。

## 最新版本策略

直接依赖经 Maven Central 核对：SnakeYAML Engine 3.2、Commons Compress 1.28.0；传递依赖约束 IO 2.22.0、Codec 1.23.0、Lang3 3.21.0。使用精确版本保持可复现，不使用动态 `+`。后续升级继续核查官方稳定发布并构建验证。

工作流提供显式更新与 Agent 更新工具；没有自动后台下载，也没有承诺每次发消息都查询所有来源。已有任务不热切换文件。手动tree URL跟随指定引用；含斜杠的分支可通过UI“指定子目录或分支”或Agent ref字段完整指定，仓库根链接和tree链接都支持。未填写ref时不自动猜测有歧义的路径。原有来源ID与JSON可继续读取，指定不同ref的新来源拥有独立ID。此历史阶段的私有认证/签名状态已由下方2026-10-26接入记录取代；插件市场仍未实现。

## 实际限制

Skills 是工作流和资源，不是完整 Linux、Node/Python 插件运行时。不会自动执行安装脚本或绕过 Android 的可执行文件/SELinux 限制。脚本可由现有命令工具用实际存在的解释器读取；可执行位仅记录在清单，不承诺导入 ELF 可直接运行。

内容哈希用于一致性校验，不证明作者可信。同 UID/Root 可改变文件，读取时校验失败会拒绝内容；这不是抵抗 Root 的沙箱。公开下载与模型凭据分离，HTTPS 重定向逐跳校验。没有真实付费模型测试。

文件符合 300 行目标；SkillManager.install 较长事务范围保留为同一异常/取消恢复单元。后续需要持续复核多包故障注入和大目录体验。

## 2026-10-26 私有来源与发布者验签
