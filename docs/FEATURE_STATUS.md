## 接续优先级

1. 已完成首轮Root/原生真机验收；继续系统工具、挂载/Root文件清理、服务强杀与管理器撤权验证。用户已于2026-10-18授权并完成本轮手机测试，不要仍把全部ARM64/Root写成未测。详见 COMPOSER_B_2026-10-18.md。
2. 后台服务、中断记录、事件驱动观看日志及0.1.14交互PTY已接入；新增能力等待最终集中设备验收，日志轮转仍未实现。不靠反复轮询或不受控守护进程维持任务。
3. Skills 与版本化工具包：使 Agent 可发现并使用工具；共享依赖按版本复用，任务固定版本，不在每轮复制大环境。
4. APK/ELF 静态分析、Root 抓包/发包，再推进动态分析与手机构建链。工具版本在采用时重新核查。
5. 真实供应商/中转的能力与缓存验收；补齐多模态与阅读体验。缓存优化以费用、时延与任务质量共同衡量。
