# 设置界面：官方 MD3 Expressive 整理

2026-11-09。用户要求先做 UI，指出设置堆砌长说明、组件不统一；随后明确批准官方 Material3 1.5.0-rc01，构建和验收后使用。比较、固定来源与候选版例外见 [UI_MD3E_PROPOSAL](UI_MD3E_PROPOSAL.md)。

## 实现

- `AuroraTheme` 使用公开 `MaterialExpressiveTheme`，采用官方排版、形状和动效默认值；保留已有动态色／预设／自定义配色设置，不另加组件库，不访问内部 API。
- `FullPage` 改为官方 `Scaffold` 和 `LargeFlexibleTopAppBar`，支持滚动收起、系统栏和键盘避让。设置首页使用官方 `SegmentedListItem` 与分段形状；不再用手写 Row 模拟顶栏或字符箭头。
- Root 状态和连接动作优先展示；授权仍在 APatch／KernelSU／FolkPatch 等管理器完成。Frida 移入 Root 页，正式策略门控仍 false，直接显示策略变更影响与禁用状态。
- 工具页按能力列出简短状态，详情默认收起；修正 APK/JNI/代理等已实现功能仍写成“开发中”的旧描述。未把已接入或已安装冒充当前运行资格。
- Linux 分离基础环境、APK 工具、版本和维护；未确认状态时不误报未安装或允许重复导入。额外准备另一执行环境时，按钮明确表示“准备”，显示原环境保留及新增文件体积；恢复待确认任务仍直接可见。
- 外观模式、配色来源和风格使用官方单选分段按钮，颜色预览／开关／滑块沿用官方组件。字体跟随系统；纯黑和彩色图标开关保留。
- Skills 首页先列工作流，按需打开安装；来源页先列配置，按需编辑；完整哈希、签名证据和 SKILL.md 正文按需查看。未认证提示与环境要求仍保留。凭据不写入可保存的 UI 状态，未保存表单返回时清空测试密钥。
- 供应商改为完整页面，字段、列表和按钮采用官方组件；系统键盘出现时保存动作仍可见。从设置进入供应商或文件空间，关闭后返回设置；模型切换确认保持在最上层。
- 浏览器上传、模型选择与文件页使用新版公开 bottom-sheet 状态工厂，保留原先只允许 Hidden／Expanded 的行为。

## 抽屉键盘问题

真机发现：新版官方抽屉打开后会请求首个可聚焦项，原先搜索框首先取得焦点；键盘出现时，旧抽屉底部入口仍在键盘后，坐标虽可见于无障碍树但实际点击落在键盘上。

修复为标题先提供非编辑焦点，页面切换清除不再需要的输入焦点，并让抽屉内容避让 IME。主动点搜索时仍允许输入，底部设置／供应商／Skills 需在键盘上方可点。最终复验结果另见精简证据；不将脚本“已发送点击”当成界面跳转成功。
