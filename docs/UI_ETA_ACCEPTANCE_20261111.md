| 路径 | 验收标准 |
| --- | --- |
| 连接配置／模型 | 配置与模型分栏清楚；新建下一步、编辑留空保留凭据，返回与删除确认正确；无真实模型调用 |
| 目录获取与选择 | 搜索、详情多选／全选、512 上限；取消或切走后旧 GET 不弹回；只增删其他模型保持当前模型，主动删除当前模型才改选 |
| 输入与菜单 | 长名称不挤爆顶栏；文本选择、粘贴、密钥显示／隐藏、IME 下一步与遮挡；原生 COUI 菜单在当前窗口定位正确，无自采样闪烁或残留 |

| 文件 | 会话／共享／工作区导航与上级返回，文件夹优先、长名称与搜索；切路径不显示旧目录，连续点读与切空间不弹旧预览；只读与 64 KiB 限制明确 |
| 浏览器上传 | 全页空间选择与系统文件入口、取消、返回和已有快照租约；不更改页面来源或自动安装 CA |
| Skills 常用 | 默认直接导入 ZIP、链接添加、列表开关；默认无认证／公钥表单。详情按需加载说明，移除确认取消无副作用 |
